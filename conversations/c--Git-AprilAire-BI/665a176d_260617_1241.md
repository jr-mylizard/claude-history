**Claude**

Next.js caches optimized images in `.next/cache/images/`. When you replace a file but keep the same filename, the old cached version keeps getting served.

Fix: stop the dev server, delete the cache folder, then restart:

```powershell
Remove-Item -Recurse -Force .next\cache\images
npm run dev
```

That clears just the image cache without a full rebuild. The new image should appear on the next page load.

**Claude**

Vercel is the natural choice for Next.js — it's made by the same team, has a generous free tier, and handles SSL and CDN automatically. Here are the full steps:

**1. Merge your branch**
Merge `dev` (or your current branch) into `master`/`main` on GitHub before connecting to Vercel, so Vercel deploys the right code.

**2. Connect to Vercel**
- Go to vercel.com → New Project → Import your GitHub repo
- Vercel auto-detects Next.js — no build config needed

**3. Set environment variables in Vercel**
Before the first deploy, add all the env vars your app needs (Settings → Environment Variables). You'll need at minimum:
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`
- `STRIPE_SECRET_KEY`
- `NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY`
- `STRIPE_WEBHOOK_SECRET`
- Any Sendinblue/Brevo keys

**4. Deploy** — Vercel builds and gives you a `*.vercel.app` URL to verify it works before switching the domain.

**5. Add your custom domain in Vercel**
Settings → Domains → add `mylizard.net` and `www.mylizard.net`. Vercel will show you the DNS records to set.

**6. Update DNS at your registrar**
- Apex domain (`mylizard.net`): add an A record pointing to `76.76.21.21`
- `www`: add a CNAME pointing to `cname.vercel-dns.com`
- SSL is automatic once DNS propagates (usually under an hour)

**7. Update Stripe webhook endpoint**
In your Stripe dashboard, update the webhook URL from whatever it was to `https://www.mylizard.net/api/webhooks/stripe`.

**8. Update Supabase allowed URLs**
In Supabase → Authentication → URL Configuration, add `https://www.mylizard.net` to the allowed redirect URLs.

Do you know what registrar your domain is at (GoDaddy, Namecheap, Cloudflare, etc.)? The DNS step varies slightly by provider.
