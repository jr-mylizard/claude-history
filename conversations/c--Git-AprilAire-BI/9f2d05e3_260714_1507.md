**How Fabric actually supports this:** Pipelines bind to Variable Library values through a `libraryVariables` block at the pipeline's `properties` level (peer of `activities`), like:
```json
"libraryVariables": {
  "Variables_SemanticModelId": { "type": "String", "variableName": "SemanticModelId", "libraryName": "Variables" }
}
```
then consumed in activity JSON as `"@pipeline().libraryVariables.Variables_SemanticModelId"`. This is confirmed by Microsoft's docs and a couple of independent write-ups, so I'm confident in the mechanism.
