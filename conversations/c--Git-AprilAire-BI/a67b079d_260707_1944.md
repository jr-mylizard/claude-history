How do I split an json array column into rows?

**Claude**

In Postgres, use `jsonb_array_elements` (or `json_array_elements` for the `json` type):

```sql
SELECT
  id,
  elem ->> 'key' AS value
FROM my_table,
jsonb_array_elements(my_column) AS elem
```

Or if it's a plain array of strings/numbers:

```sql
SELECT id, elem
FROM my_table,
jsonb_array_elements_text(my_column) AS elem
```

The comma in the `FROM` clause is an implicit `CROSS JOIN LATERAL` — each row fans out into one row per array element.
