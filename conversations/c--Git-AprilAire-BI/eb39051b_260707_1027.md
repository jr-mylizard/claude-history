**The core problem you're solving:**
Fabric's Git sync is bidirectional — if a Variable Library is in the repo, a Git → Workspace sync overwrites the workspace-specific values (connection strings, IDs, etc.). So the Variable Library needs to live outside Git, but everything that *references* it needs to be in Git and parameterized correctly.
